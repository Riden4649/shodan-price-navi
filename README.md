# タイヤ館 商談価格ナビ

## 起動方法

この版はPWA対応版です。Cloudflare PagesなどのHTTPS環境へ公開して使用してください。`file://` で `index.html` を直接開いた場合、Excel読込などの基本機能は使えますが、ホーム画面アプリ化とオフライン起動は有効になりません。

ローカル確認時は、このフォルダで簡易Webサーバーを起動し、表示された `http://localhost:ポート番号` をブラウザで開いてください。localhostはPWA開発用の安全な接続として扱われます。

## Cloudflare Pagesへの公開

ビルド作業は不要です。

1. Cloudflareへログインし、ダッシュボードの「Workers & Pages」を開きます。
2. 「Create application」→「Get started」→「Drag and drop your files」を選択します。
3. プロジェクト名を入力します。
4. このREADME、`index.html`、`manifest.json`、`service-worker.js`、`css`、`js`、`data`、`vendor`、`icons`を含むアプリフォルダ全体、または納品ZIPをアップロードします。
5. 「Deploy site」を押し、発行された `https://○○.pages.dev` のURLを開きます。

価格表ExcelはWebサイトへアップロードしません。使用時に端末上で選択し、ブラウザ内だけで解析します。

## iPadでホーム画面へ追加

1. iPadのSafariでCloudflare PagesのHTTPS URLを開きます。
2. 共有ボタンをタップします。
3. 「ホーム画面に追加」が見えない場合は「その他」を開きます。
4. 「ホーム画面に追加」を選び、「Web Appとして開く」を有効にして追加します。
5. ホーム画面の「商談価格ナビ」アイコンから起動します。

初回はオンラインで一度最後まで表示してください。以後は画面本体をオフラインでも起動できます。Excel価格表の読込に成功すると、商品データはブラウザ内に保存され、次に別の価格表を読み込むか「データをクリア」を押すまで復元されます。

## 更新方法

1. 修正版フォルダまたは修正版ZIPを準備します。
2. Cloudflare Pagesの対象プロジェクトで新しいデプロイを作成し、フォルダ全体を再アップロードします。
3. 公開完了後、iPadでアプリを一度オンライン起動します。
4. 古い画面が残る場合はアプリを完全に閉じ、Safariで公開URLを再読み込みしてからホーム画面アイコンで開き直します。

## 商談での使い方

1. 「価格表・価格設定」を開き、使用するExcel価格表を選択します。夏用価格表と2025年冬卸価格表のどちらも読み込めます。
2. 価格表を読み込むと、「ブランドを選ぶ」画面では価格表内の全ブランドと全商品が選択済みになります。不要なブランド・商品の選択だけを外します。ブランド・商品とも複数選択と「すべて選択」「すべて解除」が利用できます。
3. インチ → サイズの順に選択します。サイズ選択時に、タイヤサイズから工賃区分と「お買上時」1本工賃を自動判定します。
4. 「選択したタイヤの価格を見る」を押します。
5. 提案する商品の「お客様へ表示」を押すと、お見積書画面になります。
6. 必要なオプションをON/OFFし、「印刷」を押すと見積書として印刷できます。

## 比較提案

検索結果の商品カードで「提案する」をチェックすると、画面下部の「ご提案リスト」へ追加されます。

ご提案リストでは次の操作ができます。

- 削除
- 上下の並び替え
- おすすめ表示変更（自由入力）

お客様表示画面では、上部のタブで次を切り替えられます。

- 1枚印刷：現在の商品だけを見積書として印刷
- 比較印刷：ご提案リストの商品を比較提案書として印刷

比較印刷はA4縦1ページあたり最大4商品まで表示します。5商品以上の場合は自動的に2ページ目以降を作成します。タイヤサイズとあわせて商品コードも印刷されます。

## 店舗情報

「価格表・価格設定」の店舗情報設定で、次の内容を入力できます。

- 店舗名
- 住所
- 電話番号
- 担当者名
- 備考

初期店舗名は「タイヤ館 箕輪」です。入力内容はブラウザに保存され、お客様表示画面と印刷用見積書へ反映されます。

## 工賃・総額

「価格表・価格設定」の工賃設定で、次の1本あたり金額を変更できます。

- 組替え
- 脱着
- バランス調整
- チューブレスバルブ
- 廃タイヤ処理料
- 窒素ガス充填
- 持ち帰り袋

「工賃を含める」がONの場合、検索結果・商談画面・コピー内容へ、タイヤ4本価格、工賃4本分、工賃込み総額を表示します。OFFの場合はタイヤ本体価格だけを表示します。工賃金額とON/OFF状態はブラウザ内へ保存され、次回起動時も維持されます。

サイズ選択時は、次の「お買上時」工賃を自動反映します。

- 14インチ以下：軽・コンパクトカー、組替え1,100円 / 脱着550円 / バランス550円 / バルブ275円 / 廃タイヤ330円 / 窒素275円
- 15〜16インチ：16インチ以下、組替え1,100円 / 脱着550円 / バランス550円 / バルブ275円 / 廃タイヤ550円 / 窒素275円
- 17〜18インチ：17-18インチ、組替え1,210円 / 脱着770円 / バランス770円 / バルブ275円 / 廃タイヤ550円 / 窒素275円
- 19インチ以上：19インチ以上、組替え1,540円 / 脱着880円 / バランス880円 / バルブ275円 / 廃タイヤ550円 / 窒素275円

自動判定後も、工賃区分の手動変更、各工賃入力欄の手入力変更ができます。「自動工賃に戻す」を押すと、現在選択中のサイズから再判定した工賃へ戻ります。

初期工賃は従来どおり1本3,625円、4本14,500円です。サイズを選ぶと自動工賃へ切り替わります。

見積書に表示する項目は、次のボタンでON/OFFできます。

- 工賃
- 廃タイヤ処理料
- チューブレスバルブ
- 窒素ガス充填
- 持ち帰り袋
- 安全点検・100km点検

ONの項目だけが、お客様表示画面・印刷用見積書・コピー内容に反映されます。

初回起動直後は商品データを持ちません。Excel価格表の読込に成功した時だけ検索できます。読込成功後は、次回起動時も保存済み価格表として自動復元します。

「データをクリア」を押すと、読込商品、検索条件、検索結果、ファイル情報を削除し、価格表未読込状態へ戻ります。

## 価格計算

`（原価 ÷ ブランド別掛率 ＋ 加算額）×（1 ＋ 消費税率）`

掛率には `0.9`、`0.85`、`0.8` などの小数を入力できます。空欄または0の場合は1.0として安全に計算します。1本価格を100円単位で切り上げ、4本価格は1本価格の4倍で表示します。原価は画面に表示しません。

タイヤサイズ、ロードインデックス、速度記号は、価格表に記載されている内容を `195/65R15 91H` のような1つの「タイヤサイズ」文字列へまとめ、選択・検索結果・コピーで共通利用します。ロードインデックスや速度記号が単独の選択項目として表示されることはありません。価格表に値がない場合は、存在しない情報を補完せず、記載されている範囲だけを表示します。

サイズ選択画面では速度記号・ロードインデックスを除いた基本サイズだけを表示します。同じ基本サイズの規格違いは1カードへまとめ、カードの商品数は該当する全規格の合計です。検索結果・商談画面・コピーでは、商品のフルサイズを表示します。

## 保守

- 商品・価格：Excel価格表を更新するだけで反映できます。
- ブランド表示順・ブランド別配色：`data/brand-config.js`
- 価格計算：`js/pricing.js`
- Excel解析：`js/workbook.js`
  - 「卸価格一覧」がある価格表は正規化一覧を利用
  - 「卸価格一覧」がない価格表は各元シートの商品ブロックを直接解析
  - 2025年冬卸価格表は `PYR①` / `PYR②` / `V` / `ｱｲｽﾊﾟ` のレイアウトを自動判定して解析
  - 空欄サイズ行は直前サイズを引き継ぎ、同サイズの複数規格を取得
  - ブランド見出しを横方向に継承して、TYPE RVなどの横並び商品を取得
- 画面動作：`js/app.js`
- デザイン：`css/styles.css`

XLSM内のVBAマクロは読み込み・実行しません。

商品データはlocalStorageへ保存します。保存対象は、最後に読込成功した価格表の商品データ、ファイル名、読込日時、シート一覧です。新しい価格表を読み込むと置き換わり、「データをクリア」で削除されます。掛率・加算額・消費税率・工賃設定・工賃ON/OFFもlocalStorageへ保存します。
